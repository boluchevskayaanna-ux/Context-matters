# Context Matters
The internet is global. Opportunities are not.

## Setup
Export the existing Context Matters Database Google Sheet as Microsoft Excel (.xlsx), rename it database.xlsx, and put it beside app.py. Preserve the seven sheet names. Alternatively, upload the workbook in the app sidebar.

Install: pip install requirements.txt
Run from the project folder: streamlit run app.py

For Streamlit Community Cloud, upload app.py, requirements.txt and a reviewed database.xlsx to your repository. Do not publish personal survey data. Review source verification and publication permissions before deployment.

This prototype uses a purposive sample and predetermined profiles. It does not predict personal outcomes or provide legal advice. Some source claims and metrics remain provisional.
